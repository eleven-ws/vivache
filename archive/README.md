# 旧デザイン案アーカイブ

2026-08-12にA-ver5を公開用トップページとして確定したため、比較検証用だった旧案を本番バンドルから分離した。

## 保存対象

- `App.tsx` / `styles.css` — 旧A/B案
- `AppAVer2.tsx` / `a-ver2.css` — A-ver2
- `AppAVer3.tsx` / `a-ver3.css` — A-ver3
- `AppAVer4.tsx` / `a-ver4.css` — A-ver4
- `content.ts` / `siteConfig.ts` — アーカイブ時点の共有データ
- 旧案の設計資料・実装計画・プレビュー画像

画像素材は容量の重複を避けるため、リポジトリ直下の`image/`を共有する。アーカイブ内のTSXを再利用する場合は、作業用ブランチへコピーしてimportパスを現在の構成に合わせて調整する。
